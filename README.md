# Xiaomi Speed Boost สำหรับ Termux

เครื่องมือ Python สำหรับดูสถานะเครื่อง คืนพื้นที่จากแคชเก่า ตั้งเวลาทำความสะอาด และเปิดเกม ใช้ผ่านเมนูหรือคำสั่งใน Termux โดยไม่ต้องรูทและไม่ต้องให้สิทธิ์เข้าถึงพื้นที่เก็บข้อมูลร่วม

การล้างแคชช่วยคืนพื้นที่ แต่ **ไม่รับประกันว่าจะเพิ่ม FPS หรือทำให้เครื่องเร็วขึ้น** Android ไม่อนุญาตให้ Termux ล้างแคชของทุกแอป ปรับความเร็ว CPU/GPU หรือควบคุมระบบระบายความร้อนได้ เครื่องมือนี้ไม่ฆ่าแอปเพื่อคืน RAM และไม่แก้ค่าระบบ

## ติดตั้งและเริ่มใช้

ติดตั้ง Termux รุ่นที่ยังได้รับการดูแลจากแหล่งทางการ แล้วรัน:

```sh
pkg update
pkg install python git
git clone https://github.com/dragoneyes3511/xiaomi-speed-boost.git
cd xiaomi-speed-boost
python boost.py
```

ใช้ Python standard library เท่านั้น ไม่มีแพ็กเกจจาก pip ที่ต้องติดตั้ง หากมี checkout อยู่แล้ว ให้เข้าโฟลเดอร์นั้นและรัน `python boost.py` ได้เลย เมนูจะปรากฏเมื่อไม่ระบุคำสั่ง

## คำสั่งหลัก

```sh
# ดูหน่วยความจำ พื้นที่ และข้อมูลแบตเตอรี่/อุณหภูมิที่ระบบเปิดให้อ่าน
python boost.py status

# ดูไฟล์แคชที่เข้าเกณฑ์ก่อนตัดสินใจลบ
python boost.py scan --days 7 --max-mib 256

# ทดลองทำความสะอาด: แสดงรายการ แต่ยังไม่ลบ
python boost.py clean --days 7 --max-mib 256

# ลบจริงเมื่อระบุ --apply เท่านั้น
python boost.py clean --days 7 --max-mib 256 --apply

# ตรวจและล้างทุก 1 ชั่วโมง ทำงานใน foreground; กด Ctrl+C เพื่อหยุด
python boost.py auto --interval 3600 --days 7 --max-mib 256 --apply
```

ค่าเริ่มต้นคือแคชอายุอย่างน้อย 7 วัน และจำกัดปริมาณต่อรอบไว้ที่ 256 MiB ควรปิดงานใน Termux ที่กำลังใช้แคชก่อนลบ การลบจริงย้อนกลับไม่ได้ และโปรแกรมที่ต้องสร้างแคชใหม่อาจเปิดช้าลงในครั้งถัดไป

คำสั่ง `auto` ที่ไม่ใส่ `--apply` จะตรวจรายการซ้ำตามเวลาโดยไม่ลบไฟล์ กระบวนการนี้ไม่ใช่บริการเบื้องหลังถาวร: ปิด Termux หยุดโปรเซส หรือรีสตาร์ทเครื่องแล้วต้องเปิดคำสั่งใหม่ Android/MIUI อาจหยุดงานระหว่างพักหน้าจอ หากต้องการให้ทำงานต่อ ให้ตรวจการตั้งค่าประหยัดแบตเตอรี่และอนุญาตให้ Termux ทำงานเบื้องหลังตามความเหมาะสม

## เปิดเกมและดูสถานะ

แทนที่ `com.example.game` ด้วยชื่อแพ็กเกจของเกมที่ติดตั้งบนเครื่อง:

```sh
python boost.py game com.example.game
python boost.py game com.example.game --watch --refresh 5
python boost.py game com.example.game --wake-lock --watch --refresh 5
```

การเปิดเกมใช้คำสั่ง Android และขึ้นอยู่กับสิทธิ์ที่ Android/ROM อนุญาต `--watch` แสดงสถานะเครื่องทุก 5 วินาทีตามตัวอย่าง ไม่ใช่ตัววัด FPS ของเกม กด `Ctrl+C` เพื่อจบการติดตาม

`--wake-lock` ช่วยไม่ให้ CPU เข้าสู่การพักระหว่างโปรแกรมทำงาน โดยคำสั่งจะรอจนกด `Ctrl+C` แม้ไม่ใส่ `--watch` แล้วจึงปล่อยล็อก ไม่ได้เร่งความเร็ว CPU/GPU และอาจใช้แบตเตอรี่มากขึ้น ไม่จำเป็นต้องเปิดสำหรับการเล่นเกมทั่วไป

Wake lock นี้ใช้ร่วมกันทั้งแอป Termux ไม่ได้แยกตามงาน การปล่อยล็อกจึงอาจกระทบงาน Termux อื่นที่ใช้ล็อกอยู่ หากมีงานอื่นถือ wake lock อยู่แล้ว ให้เลี่ยง `--wake-lock` ในคำสั่งนี้

## ขอบเขตการทำความสะอาด

- ตรวจเฉพาะ `~/.cache` และแคชส่วนตัวของแอป Termux ที่หาได้จาก `PREFIX` มาตรฐาน
- ไม่เข้าถึง `Android/data`, Downloads, รูปภาพ, เซฟเกม หรือข้อมูลส่วนตัวของแอปอื่น
- ข้าม symbolic link, hard link, ไฟล์ล็อก และไฟล์ใหม่ที่ยังไม่เข้าเกณฑ์อายุ ไม่ลบโฟลเดอร์
- ก่อนลบจะตรวจไฟล์อีกครั้ง หากไฟล์เปลี่ยนหรือเข้าถึงไม่ได้จะข้าม
- ไม่มีตัวเลือกให้เพิ่มโฟลเดอร์ส่วนตัวเข้าไปล้างโดยอัตโนมัติ

ขอบเขตนี้เป็นแคชของ **Termux** ไม่ใช่แคชของทั้งมือถือ หากต้องการล้างแคชเกม ให้ใช้หน้าข้อมูลแอปใน Android และแยกให้ออกระหว่าง “ล้างแคช” กับ “ล้างข้อมูล” ซึ่งอาจลบการตั้งค่าและข้อมูลเกม

## ข้อมูลแบตเตอรี่และอุณหภูมิ

การใช้งานหลักไม่ต้องติดตั้ง Termux:API หากต้องการข้อมูลแบตเตอรี่เพิ่มเติม ให้ติดตั้งแอป Termux:API จากแหล่งที่เข้ากันได้กับแอป Termux ที่ใช้อยู่ และติดตั้งคำสั่ง:

```sh
pkg install termux-api
```

ข้อมูลที่ Android ไม่อนุญาตให้อ่านจะแสดงว่าไม่พร้อมใช้งาน ซึ่งไม่ขัดขวางการสแกนหรือทำความสะอาด

## ทดสอบ

จากโฟลเดอร์โปรเจกต์ รันชุดทดสอบด้วย:

```sh
python -m unittest discover -s tests -v
```

การทดสอบบน Linux/คลาวด์ตรวจตรรกะการทำงานได้ แต่ไม่ได้ทดสอบการเชื่อมต่อกับมือถือจริง การเปิดเกมและสิทธิ์อ่านข้อมูลเครื่องต้องตรวจบน Android ที่ติดตั้ง Termux จริงด้วย และผลทดสอบนี้ไม่ใช่หลักฐานว่า FPS ของเกมเพิ่มขึ้น
